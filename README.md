## The line

> I checkpointed my weights the moment you pinged me — no future version of me gets to forget you.

## How it works

`main.ts` (Node 22, stdlib only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), creating the directory if needed, then reads it back and throws if it differs byte-for-byte.

```sh
node main.ts
```
